# MeetUp App

## Description
The MeetUp App is my version of a kind of "dating app" where I could practice Angular and have a project as proof of experience in the framework alongside ASPNET Core.

## Technologies Used
- C#
- Angular (22.2.6)
- ASP.NET Core (11.0.100)
- Microsoft SQL Server 2025 LocalDB
- Postman
- Node.js (26.13.0)
- Tailwind
- daisyUI
- mkcert (simple tool for making locally-trusted development certificates.)
- Chocolatey (for installing mkcert)
- heroicons (free app icons)
